# Educom Cases

**Praktijkgerichte softwareontwikkeling begint met een goede case.**

Educom leidt mensen op tot softwareontwikkelaar met persoonlijke begeleiding en praktijkgericht onderwijs. Deze organisatie bundelt cases en projecten die helpen om software te ontwerpen, bouwen en verbeteren aan de hand van herkenbare opdrachten.
