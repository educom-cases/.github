# Educom Cases

**Praktijkgerichte softwareontwikkeling begint met een goede case.**

Educom leidt mensen op tot softwareontwikkelaar met persoonlijke begeleiding en praktijkgericht onderwijs. Deze organisatie bundelt cases en projecten die helpen om software te ontwerpen, bouwen en verbeteren aan de hand van herkenbare opdrachten.

## Ontdek Educom

- [Meer over Educom](https://educom.nu/educom/)
- [Alle repositories van Educom Cases](https://github.com/orgs/educom-cases/repositories)
- [Educom](https://educom.nu/)

## Samenwerken

Bekijk per repository de README voor de opdracht, doelen en werkwijze. Vragen of feedback? Open een issue in de repository waar de case thuishoort.
